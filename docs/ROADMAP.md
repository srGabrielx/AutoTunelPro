# Roadmap

## Fase 1 — entregue

- dois motores independentes;
- Trap BR, UK e EUA;
- API serverless e interface responsiva;
- seed reproduzível e prévia sonora leve.

## Fase 2

- exportação MIDI real;
- salvar projetos no Neon;
- autenticação;
- mixer de volume e swing;
- mais gêneros: drill, boom bap, funk e afrobeat.

## Fase 3

- fila assíncrona para renderização de áudio;
- samples licenciados em object storage;
- modelo ML externo opcional;
- colaboração e versionamento de projetos.
