# Golden Seeds

As Golden Seeds são as referências de regressão musical. 

Sempre que a lógica do motor for alterada, essas seeds são executadas pelo pipeline. Se o resultado (notas, hits de bateria, tensões ou timings) variar de forma não intencional, os testes quebrarão.

Isso previne a regressão de musicalidade, não apenas de código.

- `trap-br-light-002`
- `drill-aggressive-001`
